# クイヤゲーム 🐾🥟

世界のいろいろな言語・数字表記から **「9」** を見抜くゲームです。

▶ **あそぶ： https://nakanaka0318.github.io/qiy/**

## あそびかた

看板に、ある言語の言葉（または数字記号）が表示されます。

| 選択 | 意味 |
| --- | --- |
| 🐾 **クイヤを逃がす** | これは「9」だ！と予想（クイヤがシャベルのような尻尾で穴を掘って潜り、次の看板が出るとぴょこっと戻ってきます） |
| 🥟 **餃子を食べさせる** | これは「9」じゃない（ほかの数）と予想（クイヤがお皿まで歩いていき、ひとつだけの「最後の餃子」を食べます） |

- 出題は **50% の確率** で「9」を意味する言葉、残りは 7・8・10 など別の数です。
- 当たると連続記録が伸び、外れると記録はリセット。ベスト記録はブラウザに保存されます。
- 💡 **ヒント**：看板の言葉の読み方（カタカナ）を見られます。1ゲーム 3 回まで（1問につき1回）。失敗して1問目に戻ると 3 回に回復します。
- 序盤は身近な言語、中盤は世界各地の言語、そして **9問目は超難問**（言語名が伏せられ、制限時間 9 秒）。
- 最終問題では、答えるとクイヤが **ガラスを突き破って飛び込み**、割れたあとに「〇 正解！！」か「✕ 不正解…」が発表されます。正解なら 9 連続成功でクリア！
- 一度クリアすると「9の図鑑」と「超難関クイヤゲーム」が開放され、📖 ボタンから収録した「9」をすべて見られます（クリアするまでは 🔒）。

## 🔥 超難関クイヤゲーム

ふつうのクイヤゲームを一度クリアすると挑戦できます（**ヒントなし**）。タイトルの「クイヤゲーム」を押すとタイトル画面に戻れます。

- ふつうモードの最終問題レベル（各種インド系数字・ゲエズ数字・アイヌ語・チェロキー語 など）
- **昔の「9」**：印欧祖語 \*h₁néwn̥、ゴート語 niun、古代エジプト語 psḏ、シュメール語 ilimmu、アッカド語、上古・中古中国語、トカラ語、アヴェスター語、古テュルク語 など
- **文字を数に使う表記・特殊な読み**：アブジャド数字、アルメニア数字、ジョージア数字、コプト数字、中国の無線読み「勾」、航空無線「NIN-ER」
- **文字コードのない数**（SVG で描画）：インカのキープ（結縄）
- **ひっかけ**：古代ローマの `VIIII`（9）と `IIX`（8）
- **もっとマイナーな「9」**：グラゴル文字・ゴート文字・ブラーフミー数字・アッティカ数字（古代ギリシャ）・パハウ・フモン数字・アドラム数字・ンコ数字・オスマニャ数字・オルチキ数字・沖縄語「くくぬち」

超難関をクリアすると、図鑑に「超難関の9」が追加されます。
`←` / `1` 逃がす、`→` / `2` 食べさせる、`H` ヒント、`Enter` 次へ

## 🧮 クイヤ計算モード

いろいろな言語の数詞と特殊な計算がまざった式の **答えが「9」かどうか** を見抜くモードです（最初から遊べます）。
式は毎回自動で作られるので、同じ問題はほとんど出ません。ヒント（3回）を使うと、式を数字に直したものが見られます。

| 問題 | 難しさ | 言葉 | 計算 |
| --- | --- | --- | --- |
| 1〜2問目 | かんたん | ひらがな・漢字・大字・中国語（ピンイン）・英語・n進法 | 四則演算・累乗・階乗　例：`さん^two`、`11(4)+11(3)`、`拾捌÷(さん−壱)` |
| 3〜5問目 | ふつう | ドイツ語・フランス語・スペイン語・イタリア語・ポルトガル語・オランダ語・スウェーデン語・ラテン語・ポーランド語・インドネシア語 | 三角関数・逆三角関数・対数・平方根・方程式 |
| 6〜8問目 | むずかしい | エスペラント・スワヒリ語・ハワイ語・トルコ語・フィンランド語・ハンガリー語・ベトナム語・マオリ語・アラビア語・ウクライナ語・ロシア語・ギリシャ語・ヘブライ語・ヒンディー語・タイ語・韓国語・ジョージア語・各種インド系などの数字 | 微分・定積分・約数・余り・最大公約数・Σ・組み合わせ |
| 9問目 | 超むずかしい（30秒） | シュメール語・ゴート語・印欧祖語・アイヌ語・ナワトル語・文字数字（ギリシャ・ヘブライ・グラゴル・アブジャド・アルメニア・ゲエズ）・少数文字の数字・マヤ数字・キープ | 極限・行列式・固有値・次元・無限級数・複素数・重積分・ガンマ関数・オイラーのφ関数・マクローリン展開・とにかく長い式 |

問題の作り方は `js/calc.js`（テンプレートごとに答えを厳密に計算し、検証用の式も持っています）。

## 収録データ

`js/data.js` に約 290 件収録しています（「9」を表すもの 133 件）。超難関用は `js/data-ultra.js`（「9」を表すもの 34 件）。

- ヨーロッパ：英語、ドイツ語、フランス語、ロシア語、ポーランド語、フィンランド語、バスク語、アイスランド語、古英語 など
- アジア：中国語（大字含む）、日本語、韓国語、タイ語、クメール語、チベット語、モンゴル語、ヒンディー語、タミル語 など
- 中東・アフリカ：アラビア語、ヘブライ語、ペルシア語、アムハラ語、スワヒリ語、ヨルバ語、ズールー語 など
- 太平洋・アメリカ大陸：ハワイ語、マオリ語、トンガ語、ケチュア語、ナワトル語、ナバホ語、チェロキー語 など
- 数えればわかる表し方（SVG で描画）：「正」の字、画線法、トランプのマーク、そろばん、アステカ数字（点）、ヒエログリフの数字（縦線）、バビロニアの楔形数字、`3²`・`√81` などの数式
- マヤ数字（棒＝5・点＝1）、算木、n進法（`100₃`、`21₄`、`0o11` と `0x11` など）
- 数字・記号：ローマ数字、各種インド系数字、ゲエズ数字、蘇州号碼、キリル数字、ギリシャ数字、点字、モールス信号、二進数 など
- そのほか：アイヌ語、エスペラント、クリンゴン語

ひっかけ用に、`девять`(9) / `десять`(10)、`yhdeksän`(9) / `kahdeksan`(8)、`isishiyagalolunye`(9) / `isishiyagalombili`(8)、ベンガル数字 `৪`（8 に見えるが 4）など、紛らわしい組み合わせを入れています。

言葉の追加・修正は `js/data.js` に 1 行足すだけです：

```js
{ lang: "言語名", text: "表示する文字", kana: "カタカナ読み", rom: "ローマ字読み", n: 9, t: 2, note: "豆知識（任意）" },
```

`t` は難易度（1 = やさしい、2 = ふつう、3 = 超難問用）です。

## 技術メモ

- ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）。`index.html` を開けばそのまま遊べます。
- 効果音は WebAudio で合成しているため音声ファイルはありません（🔊 ボタンでミュート）。
- 多様な文字を表示するため Google Fonts の Noto フォントを読み込んでいます。
