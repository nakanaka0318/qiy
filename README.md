# クイヤゲーム 🐾🥟

世界のいろいろな言語・数字表記から **「9」** を見抜くゲームです。

▶ **あそぶ： https://nakanaka0318.github.io/qiy/**

## あそびかた

看板に、ある言語の言葉（または数字記号）が表示されます。

| 選択 | 意味 |
| --- | --- |
| 🐾 **クイヤを逃がす** | これは「9」だ！と予想（クイヤがシャベルのような尻尾で穴を掘って潜り、次の看板が出るとぴょこっと戻ってきます） |
| 🥟 **餃子を食べさせる** | これは「9」じゃない（ほかの数）と予想（クイヤがお皿まで歩いていき、ひとつだけの「最後の餃子」を食べます） |

- 出題は **50% の確率** で「9」を意味する言葉、残りは 7・8・10 など別の数です。
- 当たると連続記録が伸び、外れると記録はリセット。ベスト記録はブラウザに保存されます。
- 💡 **ヒント**：看板の言葉の読み方（カタカナ）を見られます。1ゲーム 3 回まで（1問につき1回）。失敗して1問目に戻ると 3 回に回復します。
- 序盤は身近な言語、中盤は世界各地の言語、そして **9問目は超難問**（言語名が伏せられ、制限時間 9 秒）。
- 9問連続で成功すると、クイヤが **ガラスを突き破って飛び込む** 演出でクリア！
- 一度クリアすると「9の図鑑」が開放され、📖 ボタンから収録した「9」をすべて見られます（クリアするまでは 🔒）。

キーボード：`←` / `1` 逃がす、`→` / `2` 食べさせる、`H` ヒント、`Enter` 次へ

## 収録データ

`js/data.js` に 250 件ほど収録しています（「9」を表すもの 116 件・115 言語/表記）。

- ヨーロッパ：英語、ドイツ語、フランス語、ロシア語、ポーランド語、フィンランド語、バスク語、アイスランド語、古英語 など
- アジア：中国語（大字含む）、日本語、韓国語、タイ語、クメール語、チベット語、モンゴル語、ヒンディー語、タミル語 など
- 中東・アフリカ：アラビア語、ヘブライ語、ペルシア語、アムハラ語、スワヒリ語、ヨルバ語、ズールー語 など
- 太平洋・アメリカ大陸：ハワイ語、マオリ語、トンガ語、ケチュア語、ナワトル語、ナバホ語、チェロキー語 など
- 数字・記号：ローマ数字、各種インド系数字、ゲエズ数字、蘇州号碼、キリル数字、ギリシャ数字、点字、モールス信号、二進数 など
- そのほか：アイヌ語、エスペラント、クリンゴン語

ひっかけ用に、`девять`(9) / `десять`(10)、`yhdeksän`(9) / `kahdeksan`(8)、`isishiyagalolunye`(9) / `isishiyagalombili`(8)、ベンガル数字 `৪`（8 に見えるが 4）など、紛らわしい組み合わせを入れています。

言葉の追加・修正は `js/data.js` に 1 行足すだけです：

```js
{ lang: "言語名", text: "表示する文字", kana: "カタカナ読み", rom: "ローマ字読み", n: 9, t: 2, note: "豆知識（任意）" },
```

`t` は難易度（1 = やさしい、2 = ふつう、3 = 超難問用）です。

## 技術メモ

- ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）。`index.html` を開けばそのまま遊べます。
- 効果音は WebAudio で合成しているため音声ファイルはありません（🔊 ボタンでミュート）。
- 多様な文字を表示するため Google Fonts の Noto フォントを読み込んでいます。
